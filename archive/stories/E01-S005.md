# E01-S005 — 建立 sidebar/header/main/user-menu layout

- 狀態:DONE
- Branch:story/E01-S005-sidebar-header-main-usermenu
- 日期:2026-08-13

## Scope 說明

本 story 建立 `(app)` zone 的實際視覺骨架:sidebar(導覽容器)、
header(品牌 + user-menu)、main(內容區)、user-menu(顯示目前使用者 +
登出)。**刻意排除**:permission-aware 的導覽項目集合(E01-S006 的工作;
本 story 的 sidebar 只有一個靜態「首頁」項目)、dashboard 實際內容
(E01-S007)。E01 的 20 個 story 中沒有獨立的「登出」story,登出功能的
自然歸屬就是本 story 的 user-menu。

## 變更檔案

- `apps/web/src/app/(app)/_components/sidebar.tsx` — 新增:sidebar
  容器,單一「首頁」連結,明確註解標示 permission-aware 項目留給 S006。
- `apps/web/src/app/(app)/_components/header.tsx` — 新增:品牌文字 +
  `UserMenu`。
- `apps/web/src/app/(app)/_components/user-menu.tsx` — 新增:顯示
  `useCurrentUser().userId` 的觸發按鈕、下拉選單、登出動作
  (`authClient.logout()` → `router.replace("/login")`,理由:完整換頁
  使 SessionGate 卸載重掛,下次進受保護路由會重新檢查,不會信任
  stale 的「已登入」狀態)。
- `apps/web/src/app/(app)/_components/app-shell.tsx` — 新增:組合
  Sidebar + Header + main 的整體框架。
- 對應 4 個 `*.test.tsx` — 見下方 Gate 紀錄。
- `apps/web/src/app/(app)/layout.tsx` — 改為
  `SessionGate > AppShell(children)`(AppShell 在 Server Component
  `layout.tsx` 中建構、以 children prop 傳入 SessionGate,因此 AppShell
  與其子元件的 `useCurrentUser()` 只在 session 確認後才會執行;`AppShell`
  自身及 `Sidebar`/`Header` 都不需要 `"use client"`,只有實際用到
  hook 的 `UserMenu` 需要)。
- `apps/web/src/app/(app)/layout.test.tsx` — 更新:除了驗證 children
  渲染,新增驗證 sidebar 導覽與 user-menu 觸發按鈕確實出現。
- `apps/web/src/app/(app)/page.tsx` — 移除 E01-S004 暫時性的
  「Signed in as {userId}」行:header 的 user-menu 現在永久、更合適地
  顯示目前使用者,該暫時性驗證行變得多餘(見 Assumptions)。
- `tests/e2e/specs/app-shell.spec.ts` — 新增:2 個關鍵流程 E2E(已登入
  時 chrome 正確顯示;透過 user-menu 登出後 session 真的被清除,不只是
  換頁——用「登出後重訪受保護路由會再次被導向 `/login`」驗證)。
- `tests/e2e/specs/session-gate.spec.ts` — 更新:round-trip 測試改為
  斷言 user-menu 按鈕(取代已移除的「Signed in as」文字)。

## Assumptions / 計畫外事項

1. **`logout()` 失敗路徑未處理**:目前 UI 假設
   `authClient.logout()` 總是成功(mock 的 `logout()` 實作確實總是
   回傳 `{ok: true}`,不會失敗)。真實後端的 logout 若可能失敗
   (例如網路錯誤),需要屆時視情況補上錯誤狀態——記錄為已知簡化,
   非遺漏疏忽。
2. **Sidebar 只有「首頁」一個項目**:這是刻意的、對應 S006「permission-aware
   navigation」的邊界,不是本 story 沒做完。
3. **`(app)/page.tsx` 移除 S004 的暫時性驗證行**:因為 header 的
   user-menu 現在是永久、更合適的「session 有沒有正確傳遞」證明來源;
   S004 原本預期由 S007 移除該行,但既然 S005 讓它變得多餘,現在移除
   比拖到 S007 更誠實(避免同一頁面同時出現兩處重複的使用者資訊)。
