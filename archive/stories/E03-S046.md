## 變更檔案
- `apps/web/src/lib/conversations.ts` — 新增 `readPageSize()`：讀 `NEXT_PUBLIC_CONVERSATIONS_PAGE_SIZE`，未設 → 20；合法整數 1–200 → 該值；非法（非整數／超出範圍）→ 20 + `console.warn` 記名不合法的原始值。`export const CONVERSATIONS_PAGE_SIZE = readPageSize();`——**常數改由函式初始化**（spec 給的兩個選項之一），在 module 載入時計算一次，維持既有 export 名稱、既有測試把它當純數值使用的方式完全不變。
- `apps/web/vitest.setup.ts` — 在任何測試檔案的 import 解析之前，同步設定 `process.env.NEXT_PUBLIC_CONVERSATIONS_PAGE_SIZE = "2"`，讓既有依賴分頁行為的單元測試（`conversations.test.ts` 等）看到跟改動前完全一樣的值。
- `apps/web/src/lib/conversations-page-size.test.ts`（新增）— `readPageSize()` 的 8 個測試，直接對函式呼叫、每次呼叫前改 `process.env`（`readPageSize` 每次呼叫都重讀 env，不是只在 import 時算一次，避免需要 `vi.resetModules()`）：未設→20；`"2"`→2；`"0"`/`"abc"`/`"999"`/`"2.5"`→20+warn；未設時不 warn；邊界值 1 與 200 皆合法。
- `tests/e2e/playwright.config.ts` — `web` webServer 的 `env` 新增 `NEXT_PUBLIC_CONVERSATIONS_PAGE_SIZE: "2"`，讓依賴舊分頁行為（3 顆種子對話剛好落在 2 頁）的既有 E2E spec 看到跟改動前一樣的值。
- `apps/web/.env.example` — 新增此 env 的說明與預設值註解。
- `docs/runbooks/config.md`（新增——此檔案先前不存在，本 story 是第一個引用它的 story，spec 假設它已存在但實際未被任何前置 story 建立；建立時保持最小範圍，只記錄本 story 新增的這個 env，供未來 story 擴充）— 記錄 `NEXT_PUBLIC_CONVERSATIONS_PAGE_SIZE` 的用途、預設值、合法範圍、E2E/單元測試各自如何維持 2。

## AC3 手動驗證（獨立於 E2E lock 之外的一次性驗證）
在專用 scratch port（apps/api :4200、apps/web :3010，皆非 `.e2e.lock` 保護的 3000/3001/4100，完全不佔用共用 E2E 基礎設施）啟動一組獨立、throwaway 的真實後端＋前端：

1. `apps/api`（`AI_KM_TEST_SANDBOX=true`、`AI_KM_SEED_DEMO_USERS=true`，throwaway tmp sqlite）在 4200 啟動。
2. `apps/web`（**刻意不設** `NEXT_PUBLIC_CONVERSATIONS_PAGE_SIZE`，驗證 production 預設路徑）在 3010 啟動，`API_INTERNAL_URL` 指向 4200。
3. 用 Playwright（`@playwright/test`，repo 既有 devDependency）在單一瀏覽器 session 中：登入 `demo-user` → 用該 session 自己的 cookie（`credentials:"include"`）呼叫 21 次 `POST /api/v1/conversations`（`AI_KM_TEST_SANDBOX=true` 下每次登入各自獨立 owner，必須在同一個已登入的 session 內建立，否則會建立到不同、之後看不到的 sandbox——過程中先用獨立 curl 登入建立過一次，結果第一頁只顯示 3 筆種子資料，才意識到這個既有的 sandbox 隔離特性，改成在同一個 Playwright session 內用 `page.evaluate(fetch(...))` 建立）→ 導覽至 `/conversations`。
4. 確認：該 owner 共 24 筆對話（3 種子＋21 新建，`GET /conversations?pageSize=200` 的 `totalCount` 確認）；第 1 頁 `main li` 計數 **精準等於 20**；截圖存於
   `/tmp/claude-1000/-data-python-AI-KM/b807af5a-fce6-4f12-947a-abfcd4dcb0e3/scratchpad/e03s046-conversations-page1.png`（本機 session scratch 路徑，非 repo 內檔案——手動驗證證據，非自動化測試產物，不需要進版控）。
5. 驗證後清理：kill 兩個 throwaway process、刪除 scratch sqlite、刪除臨時驗證腳本（未進 repo）。
