# Architecture Decision Records

Per `AI_KM_BMAD_High_Granularity/policies/DEVELOPMENT_POLICY.md` #12 and
`SOURCE_BASELINE.md` decision #40 ("所有跨 Domain 決策需 ADR"), every
cross-domain or cross-team architectural decision must be recorded here.

- Copy `0000-template.md` for a new ADR.
- Number sequentially, one file per decision, never edit history — supersede
  with a new ADR that references the old one if a decision changes.
- Cross-domain/cross-team decisions need review from both Team A and Team B
  before being marked Accepted.
