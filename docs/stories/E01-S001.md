# E01-S001 — 建立 Web application bootstrap 與 route skeleton

- 狀態:DONE

## Scope 說明

本 story 範圍嚴格限定為 apps/web 的「bootstrap + route 骨架」本身:route
group 結構、root layout、correlation-id middleware、全域 404。刻意排除
(並以下一個負責的 story 標明):login 視覺/互動(S002)、session/current-user
gating(S004)、sidebar/header chrome(S005)、loading/error/empty 統一樣式
(S011/S012/S013)、401/403 guard(S017)、app-level error boundary(S018)、
client 端 telemetry hooks(S019)。這些 story 尚未執行,因此本 story 對應的
Functional/Security/UX AC 中,凡屬於上述未來 story 範圍者,標記 N/A 並非
遺漏。
