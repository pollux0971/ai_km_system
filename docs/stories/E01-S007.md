# E01-S007 — 建立 Home Dashboard thin slice

- 狀態:DONE
- Branch:story/E01-S007-home-dashboard-thin-slice
- 日期:2026-08-13

## Scope 說明

本 story 把 `(app)/page.tsx` 從 S001 以來的「Scaffold placeholder」換成
真正的首頁內容:歡迎詞 + 兩個標示清楚的區塊(「最近對話」「快速入口」)。
**刻意不實作 widget 本身的邏輯**——「最近對話」是 E01-S008 的獨立
capability,「Knowledge/Maintenance/ERP 快速入口卡片」是 E01-S009
的獨立 capability。這是與 S001→S002、S005→S006 相同的「先建骨架、
下個 story 填內容」模式。SOURCE_BASELINE 舊版(§14 E01-S05)額外提到
「Favorites」,但目前 20 個細顆粒度 story 中沒有任何一個對應到
Favorites,故本 story 不發明對應區塊,留在 Assumptions 誠實記錄為
未被任何 story 認領的缺口。

## 變更檔案

- `apps/web/src/app/(app)/page.tsx` — 取代 placeholder:
  `useCurrentUser()` 顯示歡迎詞,「最近對話」「快速入口」兩個
  `<section aria-labelledby>` 區塊各自標示清楚(空狀態文字 + 註解指向
  S008/S009)。
- `apps/web/src/app/(app)/page.test.tsx` — 新增:2 個測試(歡迎詞正確
  顯示 userId;兩個區塊標題存在)。
- `tests/e2e/specs/home-dashboard.spec.ts` — 新增:1 個關鍵流程 E2E,
  登入後驗證首頁內容(歡迎詞 + 兩個區塊標題)。
- `tests/e2e/specs/login.spec.ts` / `tests/e2e/specs/session-gate.spec.ts`
  — 更新:斷言從舊標題「AI KM — apps/web」改為新標題「歡迎回來」
  (這些測試原本借用首頁標題來確認「已導向首頁」,標題文字本身不是
  它們的測試重點,更新後語意不變)。

## Assumptions / 計畫外事項

1. **未實作 Favorites 區塊**:SOURCE_BASELINE 舊版(§14)提到 Home
   Dashboard 應顯示 Favorites,但目前 20 個細顆粒度 E01 story 中沒有
   任何一個明確認領這塊。依 Anti-hallucination Guard(不確定的功能
   不可當作已存在/不可自行發明範圍),本 story 不擅自加入 Favorites
   區塊。記錄於此,待後續 story 規劃或使用者決策是否需要補一個
   story。
2. **「最近對話」「快速入口」皆為靜態空狀態**,非依角色/資料動態產生
   ——因為連接真實資料是 S008/S009 的工作。
3. **首頁標題文字變更**(「AI KM — apps/web」→「歡迎回來」)影響了
   3 處既有 E2E 斷言(login.spec.ts x2、session-gate.spec.ts x1)。
   這些測試借用首頁標題只是為了確認「已成功導向首頁」,已同步更新,
   語意與覆蓋範圍不變。
